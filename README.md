# 🎬 Gerenciador de Séries

Aplicação web desenvolvida para pesquisar séries de televisão, consultar suas informações e salvar as favoritas. O projeto foi criado com o objetivo de praticar desenvolvimento web com JavaScript, consumo de APIs e manipulação do DOM.

## 🚀 Funcionalidades

* 🔎 **Busca de séries:** pesquisa séries pelo nome.
* ⭐ **Informações das séries:** exibe pôster, título, nota e gêneros quando disponíveis.
* ❤️ **Sistema de favoritos:** permite adicionar e remover séries dos favoritos.
* 💾 **Persistência de dados:** mantém os favoritos salvos no navegador usando `localStorage`.
* 📱 **Interface responsiva:** adapta a exibição a diferentes tamanhos de tela.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* [TVMaze API](https://www.tvmaze.com/api) — consulta de informações sobre séries.
* LocalStorage — armazenamento local dos favoritos.
* Font Awesome — ícones da interface.

## 🧠 Aprendizados

Durante o desenvolvimento, pratiquei:

* Manipulação do DOM e criação dinâmica de elementos.
* Eventos e interações com botões.
* Modularização com `import` e `export`.
* Requisições HTTP utilizando `fetch` e programação assíncrona com `async/await`.
* Conversão de dados com `JSON.stringify()` e `JSON.parse()`.
* Armazenamento e recuperação de informações com `localStorage`.
* Organização do código em módulos e separação de responsabilidades.
